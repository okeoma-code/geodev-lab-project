# my Geodev-lab-project
https://github.com/okeoma-code/geodev-lab-project/projects
How accessible is each settlement area in Owerri West to health facilities?

Built over twelve months with GeoDev Lab Africa, Cohort One.
See project-brief.md for the full brief.

## Month 1: Intro to GIS and Data download
- Week 1: Chose a research question for my project and searched for data sources containing the required data to answer the question.
- Week 2: Learned about spatial analysis and downloaded the data required for my analysis.
- Week 3: Learned about coordinate systems and cleaned my data.
- Week 4: Learned about spatial relationships and conducted spatial analysis using my data.

## Month 2: development environment and early Python
- Week 5: Set up Python, VS Code and installed UV. Also python_hello.py runs
- Week 6: Set up UV, added pandas, created check.py, used UV to run the code, and check.py prints pandas version.
- Week 7: Learned the six ideas, created analyse.py and wards.csv, used UV to run the code, it reads, converts area and also classifies the wards.
